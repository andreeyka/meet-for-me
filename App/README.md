# App — модуль `app-ui`, владелец DEV-3

Здесь живут App-таргет (меню-бар, окна, настройки, мастер прав) и composition root —
единственное место, где порты домена связываются с конкретными реализациями.

Каркас Xcode-проекта (`project.yml` для XcodeGen, entitlements, подпись) добавляет архитектор
отдельной задачей, когда у `app-ui` появится первый код: проверить генерацию и подпись можно
только на Mac, поэтому вслепую этот файл не пишется.

Запрещено: обращаться к `Storage`, к движку и к системным адаптерам мимо домена (П7).
