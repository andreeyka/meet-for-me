# meet-for-me

macOS-приложение для автоматической записи и транскрибации встреч (menu bar, Swift/SwiftUI, Apple Silicon M2+, macOS 14.2+).

## Источники истины

- **Архитектура** — [`docs/architecture.md`](docs/architecture.md). Структура системы, границы компонентов, интерфейсы, выбор технологий, журнал решений. Решения оттуда не пересматриваются в коде: нужно изменить — запрос на изменение архитектуры (метка `arch-request` в Linear).
- **Работы** — Linear, команда MEE. Задачи, контракты интерфейсов, критерии приёмки, статусы. Пакет задачи целиком лежит в описании issue.

## Правила работы с кодом

- Модуль имеет одного владельца; разработчик изменяет только файлы каталогов своего модуля.
- Интерфейсы (протоколы, DTO, схема БД, XPC-сообщения, форматы файлов) принадлежат архитектору и меняются только через `interface-request`.
- Одна задача — один модуль — один PR.
