# spikes — код вне модулей

Спайк снимает риск, а не поставляет продукт: результат — измерения и выводы комментарием в issue,
обновление допущений `docs/architecture.md` и тестовые данные для следующих этапов.

Правила: каждый спайк — свой каталог `spikes/<имя>/`; владелец назначается задачей; код отсюда
не переезжает в модули без отдельной задачи с контрактом. CI спайки не собирает.
