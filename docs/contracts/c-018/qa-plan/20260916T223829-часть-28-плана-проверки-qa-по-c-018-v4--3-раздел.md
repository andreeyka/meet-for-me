## §3. План — 93 пункта, по одному на критерий

**Колонка «Различающий вектор» отвечает на один вопрос: какую **названную** неверную реализацию этот вход красит красным.** Пункт без такого вектора есть пункт, зелёный по построению, и такие пункты план называет сам — §5, а не прячет среди прочих.
